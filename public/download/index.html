eChopdo

eChopdo for Android

The whole eChopdo app, plus a home-screen widget to add Hisab or Budget entries in a couple of taps.

⬇ Download eChopdo
Android 8 or newer

Install

  1. Tap Download, then open the file.
  2. If Android asks, allow Install unknown apps for Chrome (only once).
  3. If Play Protect says “App blocked to protect your device” (it blocks any app from outside the Play Store that can read SMS): open the Play Store → your profile picture → Play Protect → ⚙ → turn off Scan apps with Play Protect, install eChopdo, then turn it back on. Do the same for each update, unless automatic updates are on (eChopdo → Phone settings → Updates): then the app downloads and installs new versions itself.
  4. If Play Protect only warns “unknown developer”, tap More details → Install anyway.
  5. Open eChopdo. It's the same app as before — sign in or unlock as usual. You can remove the old eChopdo icon afterwards.

Turn on the widget

  1. In eChopdo open ⚙ Settings → Phone widget → Pair a phone.
  2. Tap Pair this phone, then Add widget to home screen.

What you get

  • Widget — Spent / Received, and one-tap buttons for things you add often (with Undo).
  • Quick add — calculator keypad, category, book, paid by, date. Saves to Hisab (or Budget — your choice per phone).
  • Shortcuts — long-press the eChopdo icon, or the “eChopdo +” tile in the notification shade.
  • Bank SMS — UPI and card payments from bank SMS show up ready to add in one tap (turn on in the app: long-press the icon → Phone settings). The SMS never leaves your phone.
  • Works offline — entries wait and send when you're back online.

A paired phone can only add entries to its household. Unpair any time in Settings → Phone widget.
