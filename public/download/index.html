GRANDXGAMER

Shop phone app (Android)

For the café's phone that gets the bank's SMS. It reads every “money received” SMS and sends only the amount, time, payer and UPI ref to the shop, which matches it to a booking or a customer. It also opens the GRANDXGAMER app full screen.

⬇ Download the app
Android 8 or newer

1 · Install

  1. Tap Download, then open the file. If Android asks, allow Install unknown apps for Chrome (once).
  2. If Play Protect says “App blocked to protect your device” (it blocks any app from outside the Play Store that can read SMS): open the Play Store → your profile picture → Play Protect → ⚙ → turn off Scan apps with Play Protect, install, then turn it back on.
  3. If it only warns “unknown developer”, tap More details → Install anyway.

2 · Pair with the shop

  1. On the owner's login: GRANDXGAMER → ⚙ → Bank SMS phone → Pair the shop phone. An 8-character code appears.
  2. On the shop phone open the app → Bank SMS settings (or tap Pair this phone if the code is on this phone) and type the code.

3 · Allow the bank SMS

  1. Tap Turn on bank SMS → Allow.
  2. If Android blocks it (“restricted setting”): App info → ⋮ → Allow restricted settings, confirm, come back and tap Try again.
  3. It looks back 7 days once, then reads each new SMS as it arrives. SMS log shows what it read and why.
  4. Turn on automatic updates on the same screen — new versions then install by themselves.

Keep the phone on and online at the shop. Payments read while it's offline are sent when it reconnects. Money going out is never sent.
